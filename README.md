# ClassSentinel 课堂哨兵
> Android 端纯离线课堂语音提醒工具 | 本地识别 · 隐私安全 · 点名提醒

## 项目介绍
ClassSentinel（课堂哨兵）是一款专为高校课堂场景设计的Android离线语音提醒应用。应用通过本地离线语音识别引擎实时监听课堂语音，当识别到老师点名、提问类关键词或**你的名字**时，自动通过悬浮横幅、通知、震动、提示音多维度发出提醒，并**以大字突出展示老师念的题目**，帮助用户及时响应课堂互动。

**所有语音识别与逻辑处理均在设备本地完成，全程不联网、不上传任何音频数据，在实现功能的同时完全保障隐私安全。**

## 界面结构（v2.5 重构）

```
主界面 ------ 语音识别框（上方：状态 + 实时识别文本）
        ------ 设置按钮（右上 ⚙）--- 设置页（全部设置收纳于此）
        ------ 监听按钮（中间：大圆按钮，点击开始/停止）
        ------ 最近提醒（下方：报警后显示「题目」大字 + 原话）
```

报警时最先要看的是老师念的题干——悬浮横幅、系统通知、主界面提醒卡三处统一**题目大字优先**，原话识别文本降为辅助信息。

## 核心功能
- 🎙️ **纯离线语音识别**：基于 sherpa-onnx 离线流式语音识别引擎，所有运算本地完成，无网络依赖
- 🔀 **双模型可选（v2.5+）**：设置里一键切换——
  - **标准 · 中英双语**（默认，190MB）：中文精度最高，真人远场更准，热词偏置生效
  - **轻量 · 中文专用**（25MB）：词表零英文，英文碎片彻底根除，加载快省电，适合中低端机型
- 🔔 **三类关键词触发**：核心词 / 语境词（可跨句门控）/ 排除词，默认内置 31 组触发词，支持自由增删，改词即时生效
- 👤 **名单匹配 + 姓名读音纠偏（v2.0+）**：录入姓名与别名，老师点到名字即提醒；⭐标记"我的名字"走定向强提醒
- 🔤 **读音层语义校验（v2.1+）**：内置 2 万字拼音表 + 容错对齐——
  - 同音错字自动命中（"张三"→"章三"）
  - 近似音匹配（"阳一真"→"阳丽真"，声母不同韵母相同）
  - 吞字容错（"阳一真"被吞成"养一"也能命中）
  - 单字展开容错（"找个同学"被识别成"找个一同学"）
  - 命中后自动把识别文本**写回真名**，转写与提醒显示正确姓名
- 🧹 **识别文本清理（v2.4+）**：自动折叠 ASR 卡顿重复（"动动能定定定理"→"动能定理"）、过滤英文幻觉碎片（保留 MONDAY 等正常英文词）
- 📊 **置信度分级**：精确命中一律全量提醒；猜测性命中按置信度降级轻量通知，压降误触发
- 📝 **课堂转写（默认关）**：每句话存本机数据库，回看/复制/分享，触发句标 ▶
- ⬇️ **快捷磁贴**：下拉快捷面板一键开/关监听
- 📱 **三重提醒机制**：悬浮横幅（题目优先）+ 通知 + 震动 + 提示音；冷却时间可配
- ⚡ **后台稳定保活**：前台服务常驻 + 划走任务自动恢复 + 各国产 ROM 自启动一键跳转；不申请开机自启
- 📋 **触发历史记录**：自动留存最近 50 条触发记录（含题目、原话、置信度）
- 🧪 **自测工具**：提醒效果测试、语音自测、**姓名识别探针**（对比热词偏置效果），无需麦克风即可验证全链路

## 技术特点
- 识别框架：sherpa-onnx v1.13.6，双模型内置——190MB 中英双语 int8（默认）与 25MB 中文专用 int8（zh-14M），SHA-256 完整性校验按所选模型执行
- 解码优化：modified_beam_search + 热词偏置（花名册与关键词注入解码器），CJK 字符建模单元
- 语义后处理：读音容错对齐（DP，插入预算按词长分级）+ 卡顿折叠 + 粘连英文噪声过滤，匹配用原始文本、展示用清理文本，互不干扰
- 音频处理：自动启用系统降噪与增益，三段式端点检测适配课堂远场带噪场景
- 技术栈：Kotlin + Jetpack Compose（Material 3），兼容 Android 8.0+，仅支持 arm64 真机

## 适用场景
- 通识课、公共选修课等低强度课堂，避免走神错过点名
- 需要同时处理其他事务的课堂，辅助及时响应提问
- 听力障碍、注意力不集中人群的课堂辅助工具
- 等等....你懂的


## 🛠️ 从源码构建

```bash
git clone https://github.com/Alsn-123/ClassSentinel.git
cd ClassSentinel
./gradlew assembleDebug   # Windows: gradlew.bat assembleDebug
```

> ⚠️ **注意**：标准双语模型的 `encoder-int8.onnx`（约 173 MB）超出 GitHub 单文件 100 MB 硬限制，**未纳入版本库**。
> 从源码构建前，请先获取该文件放入 `app/src/main/assets/asr-model/`，
> 否则应用可编译但标准模型不可用（轻量中文模型已完整入库，功能不受影响）。若只需使用，请直接下载 Releases 中的 APK。

```
app/src/main/assets/
├── asr-model/          ← 标准双语模型
│   ├── encoder-int8.onnx   ← 需自行获取（约 173 MB）
│   ├── decoder-int8.onnx   ← 已在仓库中
│   ├── joiner-int8.onnx    ← 已在仓库中
│   └── tokens.txt          ← 已在仓库中
└── asr-model-zh/       ← 轻量中文模型（四件套全部已在仓库中，约 25 MB）
    ├── encoder-int8.onnx
    ├── decoder-int8.onnx
    ├── joiner-int8.onnx
    └── tokens.txt
```

### Release 签名（可选）

`signingConfigs.release` 从项目根 `keystore.properties` 读取签名凭据（不入库，`.gitignore` 已忽略）。配置缺失时 release 构建回退为未签名，CI 不受影响。**自签 keystore 务必备份**：更换证书后已安装用户需卸载重装。
