# ClassSentinel 课堂哨兵
> Android 端纯离线课堂语音提醒工具 | 本地识别 · 隐私安全 · 点名提醒

## 项目介绍
ClassSentinel（课堂哨兵）是一款专为高校课堂场景设计的Android离线语音提醒应用。应用通过本地离线语音识别引擎实时监听课堂语音，当识别到老师点名、提问类关键词时，自动通过悬浮窗、震动、提示音多维度发出提醒，并同步展示提问语句与前文上下文，帮助用户及时响应课堂互动。

**所有语音识别与逻辑处理均在设备本地完成，全程不联网、不上传任何音频数据，在实现功能的同时完全保障隐私安全。**

## 核心功能
- 🎙️ **纯离线语音识别**：基于 sherpa-onnx 离线流式语音识别引擎，内置全量双语识别模型，所有运算本地完成，无网络依赖
- 🔔 **三类关键词触发**：核心词 / 语境词（可跨句门控）/ 排除词，默认内置 39 组触发词，支持自由增删，改词即时生效
- 👤 **名单匹配（v2.0+）**：录入姓名与别名，老师点到名字即提醒；⭐标记"我的名字"走定向强提醒
- 🔤 **同音错字自动命中（v2.1+）**：内置 2 万字拼音表，"张三"被识别成"章三"也能触发，无需手动录错字
- 📊 **置信度分级（v2.0+）**：低置信命中只发轻量通知，压降误触发；历史记录带置信度
- 📝 **课堂转写（v2.2+，默认关）**：每句话存本机数据库，回看/复制/分享，触发句标 ▶
- ⬇️ **快捷磁贴（v2.2+）**：下拉快捷面板一键开/关监听
- 📱 **三重提醒机制**：悬浮横幅展示识别内容+前文上下文、设备震动、提示音同步提醒；冷却时间可配
- ⚡ **后台稳定保活**：前台服务常驻 + 划走任务自动恢复 + 各国产 ROM 自启动一键跳转；不申请开机自启
- 📋 **触发历史记录**：自动留存最近50条触发记录，支持随时回看
- 🧪 **自测调试工具**：提醒效果测试、语音自测，无需麦克风即可验证识别与提醒链路

## 技术特点
- 识别框架：集成 sherpa-onnx v1.13.6，默认搭载 190MB 中英双语流式int8量化模型，识别完整度优异
- 解码优化：支持热词偏置解码，通过 modified_beam_search + CJK字符建模单元提升目标关键词识别准确率
- 音频处理：自动启用系统降噪，搭配三段式端点检测，适配课堂远场、带噪的复杂语音场景
- 技术栈：Kotlin + Jetpack Compose 构建，兼容 Android 8.0 及以上系统，仅支持 arm64 架构真机
- 功耗优化：轻量化后台服务设计，长时间监听对设备续航影响小

## 适用场景
- 通识课、公共选修课等低强度课堂，避免走神错过点名
- 需要同时处理其他事务的课堂，辅助及时响应提问
- 听力障碍、注意力不集中人群的课堂辅助工具
- 等等....你懂的


## 🛠️ 从源码构建

```bash
git clone https://github.com/Alsn-123/ClassSentinel.git
cd ClassSentinel
./gradlew assembleDebug   # Windows: gradlew.bat assembleDebug
```

> ⚠️ **注意**：识别模型 `encoder-int8.onnx`（约 173 MB）超出 GitHub 单文件 100 MB 硬限制，**未纳入版本库**。
> 从源码构建前，请先获取该模型文件并放入 `app/src/main/assets/asr-model/` 目录，
> 否则应用可以编译通过但无法进行语音识别。若只需使用，请直接下载上方 Releases 中的 APK。

```
app/src/main/assets/asr-model/
├── encoder-int8.onnx   ← 需自行获取（约 173 MB）
├── decoder-int8.onnx   ← 已在仓库中
├── joiner-int8.onnx    ← 已在仓库中
└── tokens.txt          ← 已在仓库中
```
